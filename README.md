# Digital Monster

## Проверка с телефона по Wi-Fi

Компьютер и телефон должны быть подключены к одному роутеру. Компьютер может
использовать Ethernet, а телефон — Wi-Fi.

```sh
npm run dev
```

Открыть на телефоне адрес из строки `Network` в терминале, например
`http://192.168.0.157:5173/`. Изменения исходников обновляются автоматически.
Терминал с сервером должен оставаться запущенным; остановка — `Ctrl+C`.
На компьютере по-прежнему работает `http://localhost:5173/`.

Обычный dev-запуск использует быстрый старт. Чтобы проверить полный прогрев,
как в production, добавить `?fullWarm=1` к адресу:
`http://192.168.0.157:5173/?fullWarm=1`.
Качество графики по умолчанию выбирается автоматически; для проверки конкретного
режима можно добавить `&tier=low`, `&tier=medium` или `&tier=high`.

Для проверки собранной production-версии локально:

```sh
npm run build
npm run preview
```

Открыть адрес `Network` на порту `4173`. После изменений исходников сборку нужно
повторить. В production-сборке `fullWarm` включён всегда, в том числе при
`?fullWarm=0`; дополнительные параметры для прогрева не нужны.
Деплой также выполняет `npm run build`.

Если телефон не подключается:

- Проверить актуальный адрес `Network`: IP компьютера может измениться.
- Перезапустить старый сервер без `--host 127.0.0.1`: этот аргумент перекрывает
  настройку доступа по сети.
- Проверить, что Windows разрешает входящие подключения для Node.js в текущем
  сетевом профиле.
- Подключить телефон к основной сети роутера: гостевая Wi-Fi сеть, изоляция
  клиентов или VPN могут мешать доступу к компьютеру.
- Если порт занят, остановить прежний сервер. Порты фиксированы: `5173` для dev,
  `4173` для preview, без автоматического перехода на другой порт.

[production deployment](scripts/deploy/README.md).
