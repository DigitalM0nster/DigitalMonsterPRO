# ScrollPageNavigator template

Архивная реализация прежнего правого линейного навигатора основных страниц.
Она больше не монтируется в приложении: вместо неё используется
`src/components/HTML/components/SiteArcNavigator`.

Папка сохранена как готовый шаблон со стилями и About-адаптером. Перед повторным
подключением проверьте состав `MAIN_ITEMS`: текущая версия зафиксирована на момент
замены и не включает дальнейшие изменения реестра маршрутов.
