# Digital Monster / Creature handoff

**Статус: реальная 3D-заготовка для дальнейшей работы, не финальная копия утверждённой картинки.**

Файлы GLB содержат объёмную геометрию. Их можно вращать, рассматривать с разных сторон и использовать как начало моделирования. Приложенные превью отрендерены из этих файлов, а не сгенерированы как имитация 3D. Оригинальные утверждённые изображения находятся отдельно в `references/`.

## Что открыть

| Файл | Назначение |
|---|---|
| `models/dm_creature_base.glb` | Чистая геометрия с нейтральным материалом, 26 400 треугольников, 8 объектов |
| `models/dm_creature_lookdev.glb` | Та же основа с отдельными статическими точками и линиями для оценки направления |
| `models/dm_creature_base.obj` | Альтернатива для редактирования: исходная сетка с группами и четырёхугольными участками |
| `CODEX_TASK_RU.md` | Полное задание на сходство, моделирование, материалы, риг и интеграцию |
| `assemble_blender.py` | Сборка новой сцены Blender из исходных данных, с редактируемыми кривыми и точками |
| `data/creature_source.json.gz` | Исходные поверхности, UV, кривые и точки; читаются скриптом сборки |
| `data/surface_samples.npz` | 21 955 статических якорей точек: positions, radii, part_indices, uv, landmarks |
| `data/validation.json` | Фактически выполненные проверки геометрии и повторного чтения GLB |
| `previews/` | Настоящие рендеры заготовки с разных сторон |

## Что передать Codex

Передать весь распакованный каталог. Стартовое сообщение:

> Прочитай CODEX_TASK_RU.md. В references/ лежат утверждённые изображения персонажа; они важнее упрощённой геометрии в models/. Собери сцену в Blender через assemble_blender.py, проверь её, затем доведи модель до референсов. Не делай нового обычного кита. Сначала покажи проверку головы и распрямлённого силуэта на нейтральном материале; затем доработай светящиеся точки, линии и анимацию. Интерфейс и океан Digital Monster не менять. Не заявляй о готовности .blend или рендера, пока они фактически не созданы и не проверены.

## Сборка .blend

В комплекте **нет уже сохранённого .blend**: в среде подготовки не было Blender. GLB/OBJ созданы и прочитаны повторно; для Blender-скрипта проверен только синтаксис Python. Возможную несовместимость API установленной версии должен проверить исполнитель.

В терминале, где доступен Blender, из этой папки:

```sh
blender --background --factory-startup --python assemble_blender.py -- --mode lookdev
```

Планируемый результат: `models/dm_creature_blockout.blend`. Для нейтральной версии:

```sh
blender --background --factory-startup --python assemble_blender.py -- --mode clay --out models/dm_creature_clay.blend
```

Флаг `--render-preview` дополнительно запускает рендер после сохранения сцены. Для существующего выходного файла нужен явный `--overwrite`. Сборщик не требует сторонних пакетов Python и не отправляет данные по сети. Для отдельного генератора `build_geometry.py` нужны numpy, scipy, trimesh; его запускать не обязательно.

## Важные ограничения

Голова, скрытые стороны, глазницы и точечный рисунок пока приближённые. Исходная картинка имеет приоритет над любыми отличиями заготовки.

Корни плавников являются отдельными пересекающимися замкнутыми деталями. Для профессиональной деформации требуется доработка стыков/топологии. GLB не содержит риг, анимацию и LOD. Точки и линии статичны и ещё не следуют костям. Свечение на PNG дополнено постобработкой; любой сторонний просмотрщик GLB может показывать материал без такого ореола.

`dm_creature_lookdev.glb` — наглядный пример, не оптимизированный для прямого использования на сайте. Для Babylon.js/WebGPU нужен отдельный рендер точек и линий, связанный с деформируемой поверхностью. 60 FPS — цель дальнейшей интеграции, не измеренный результат.

Исходные JSON и OBJ: Z вверх, −X вперёд. В GLB записано преобразование к Y-up: (x, y, z) → (x, z, −y). Размеры условные; длина от носа до кончиков хвоста примерно 11,53 единицы.

## Проверки

Каждая основная поверхность имеет конечные координаты, замкнутую сетку и положительный объём. Оба GLB повторно загружены через trimesh. Проверка открытия в Blender, рига, анимации, точности сходства и производительности браузера **не проводилась**. Подробности: `data/validation.json`.
