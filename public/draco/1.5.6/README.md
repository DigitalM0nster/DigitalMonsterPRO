# Draco 1.5.6 decoders

Unmodified decoder files from https://www.gstatic.com/draco/versioned/decoders/1.5.6/.
The exact existing decoder version is served from the site origin so an unavailable
Google CDN cannot block scene readiness at 39–41%. Both WASM and JavaScript fallback
are included; the encoder is not needed at runtime.
